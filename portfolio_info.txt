Project:Command Line Interface( CLI ) library for microcontrollers.

Company:Minard

Date:Apr 2023 – Oct 2023

Info:
I made a complete repository to implement a CLI (Command Line Interface) in a C++ based MCU. The library allows the creation of a C++ object to manage the CLI data flow in a 16-bit architecture. The library uses a buffer that separates the command name and command arguments. Then, a superclass called ‘Command’ creates a buffer and a vector with the commands allowed during all the program execution in the MCU. Each command can be linked to an MCU function or process for programming data and retrieving values. The library works with any communication interface such as Serial, I2C, SPI, CAN, Modbus, etc. Each time a new character arrives at the communication interface, the library adds this character to the objects. Once each character from the data arrives, and when two command terminator characters are received, the library separates and manages each data from the command. This library allows the implementation of any command name for any embedded system. You can write commands based on the NMEA and ANSI standards.

Skills:C++,ESP32 Microcontrollers,Atmel AVR
